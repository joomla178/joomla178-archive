### 背景资料

如果你不知道ＣＳＶ以及为什么要用他，点击[这里](http://www.csvimproved.com/overviewow-to-csvi.html) 查看更多说明

### 下载 CSV Improved

![tutuploadsmedia_1303583139277.png](http://www.ostraining.com/images/stories/tutuploadsmedia_1303583139277.png)

我们将要用 [CSV Improved](http://www.csvimproved.com/)  来导入CSV. [点击去直接下载](http://www.csvimproved.com/csv-improved/csvi-virtuemart/releases/view-category.html) . 你必须注册后并登录才能下载

### 安装 CSV Improved

![tutuploadsmedia_1303583994454.png](http://www.ostraining.com/images/stories/tutuploadsmedia_1303583994454.png)

前往 Extensions >> Install/Uninstall >> Browse... >> Upload File & Install

### 先导出这样你就有个样品

![tutuploadsmedia_1303714112583.png](http://www.ostraining.com/images/stories/tutuploadsmedia_1303714112583.png)

此教程是为了导入, 但这里有个小窍门来获得一个样品文件，这样你就不用从头开始创建了，从而节省你的时间并减少用户错误的机会。为了执行这捷径方式, 你需要创建至少一个商品在 Virtuemart里.

一旦你在Virtuemart里创建了商品, 前往 Components >> CSVI Virtuemart >> Export.

![tutuploadsmedia_1303714806738.png](http://www.ostraining.com/images/stories/tutuploadsmedia_1303714806738.png)

选择 CSVI Product Export. 其余的默认设置就行

![tutuploadsmedia_1303714842863.png](http://www.ostraining.com/images/stories/tutuploadsmedia_1303714842863.png)

导出CSV文件到你电脑

### 使用导出了的CSV文件做参考

![tutuploadsmedia_1303715105718.png](http://www.ostraining.com/images/stories/tutuploadsmedia_1303715105718.png)

打开这文件并看看你现在有了基本的结构，你只需按这格式匹配原始的CSV.如果你不确定所有这些信息的意思，请查看在后台顶部页面的对话信息

![tutuploadsmedia_1303716218495.png](http://www.ostraining.com/images/stories/tutuploadsmedia_1303716218495.png)

一旦你完成了你的CSV格式, 然后前往 Import >> CSVI Product Import >> Browse...

![tutuploadsmedia_1303716464740.png](http://www.ostraining.com/images/stories/tutuploadsmedia_1303716464740.png)

Import,然后你要仔细检查你的表格确保所有都匹配, 一旦完成后再次点击 Import . 现在你可以前往Virtuemart 并仔细检查所有这方面的
