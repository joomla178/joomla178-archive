# joomla常见问题解决方案

本站罗列了一些常见的问题，希望能为大家提供帮助

**joomla 首页显示JPAGE\_CURRENT\_OF\_TOTAL 解决方法**

这个问题是由于，语言包中没有设置参数造成的，打开语言包的主文件，例如中文语言包：zh-CN.ini 在里面查询 “JPAGE\_CURRENT\_OF\_TOTAL” 如果没有，请加入 “JPAGE\_CURRENT\_OF\_TOTAL=页数 %s / %s” 即可

鉴于不愿意修改底层代码的网友，本站压缩至language文件夹，下载解压至根目录，覆盖即可（请注意备份）

[下载修改翻页中文解压包](http://www.joomla178.com/download/file/12-page-for-chinese.html)

**joomla 搜索字数至少3个字符修改**

找到文件 administrator\components\com\_search\helpers\search.php

大约72行左右

// searchword must contain a minimum of 3 characters

if ( $searchword && JString::strlen( $searchword ) < 3 ) {

……

将(searchword)<3 改成 (searchword)<1

鉴于不愿意修改底层代码的网友，本站压缩至administrator文件夹，下载解压至根目录，覆盖即可（请注意备份）
