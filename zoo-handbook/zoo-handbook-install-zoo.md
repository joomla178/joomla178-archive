一. 安装ZOO

安装ZOO，使用Joomla后台的扩展管理（Extensions Installer）进行安装

进入该页面进行上传安装 ： Joomla后台 » Extensions » Install/Uninstall.

![1](http://www.okjoomla.com/images/tutoria1/02/1.png)

- 当您上传安装的过程遇到问题时，建议您使用“从文件夹安装“（Install from directory）进行安装：
- 下载最新版本的ZOO到您的电脑，并将其解压
- 使用FTP软件，上传解压后的ZOO左右文件到 您的Joomla网站目录中/tmp 文件夹中
- 进入页面：Joomla后台 » Extensions » Install/Uninstall，选择 “从文件夹安装”，之后选择您上传到 /tmp 中的ZOO文件夹
- 点击 安装按钮 ，系统将会进行安装ZOO软件

ZOO的系统要求：

- Joomla 2.5+
- PHP 5.2.7+
- PHPs GD extension (enabled in PHP 5.0+)
- PHPs SimpleXML extension (enabled in PHP 5.0+)
- PHPs DOM extension (enabled in PHP 5.0+)
- PHPs allow\_url\_fopen support (enabled in PHP 5.0+)
- PHPs cURL extension - is needed for Facebook Connect to work.
- MySQL 5.0.4+ (MSSQL is not supported)
- We recommend Apache 2.x + with mod\_mysql, mod\_xml and mod\_zlib. Minimum requirement 1.3
- Mod\_rewrite for Apache for search engine friendly links

注：上述的系统要求，不必担心，或一一费力地查询。只有当安装ZOO出错时，我们再去排查是不是因为没达到系统要求的问题所引起的即可。
